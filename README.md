# Portfolio Web Personal

Portfolio profesional desarrollado para mostrar mi trayectoria, habilidades técnicas y proyectos destacados como **Desarrollador Web y Diseñador UI**.

## Tecnologías utilizadas

* **HTML5** (Estructura semántica y accesible)
* **CSS3** (Variables CSS, Grid, Flexbox y diseño responsive)
* **JavaScript (Vanilla)** (Interactividad basica y control de scroll)

## Estructura del proyecto

* `index.html` — Página principal del portfolio.
* `css/style.css` — Estilos globales, componentes y adaptabilidad móvil.
* `js/main.js` — Lógica de navegación y comportamiento de la interfaz.
* `assets/docs/` — Documentación y CV en formato PDF.
* `assets/img/` — Imágenes, iconos y capturas de proyectos.
